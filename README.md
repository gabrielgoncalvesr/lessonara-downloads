# Lessonara Desktop

Aplicativo de chamadas do Lessonara para Windows x64 e Mac com Apple Silicon. O portal de gestão continua no navegador.

[Baixar a versão de teste 0.3.1](https://github.com/gabrielgoncalvesr/lessonara-downloads/releases/tag/desktop-v0.3.1)

- **Windows:** baixe `Lessonara-0.3.1-windows-x64-setup.exe` e instale na sua conta. O instalador registra os links `lessonara://`.
- **Mac Apple Silicon:** baixe `Lessonara-0.3.1-mac-arm64.zip`, extraia e mova Lessonara.app para Aplicativos.
- Entre com sua conta de professor. Use **Abrir no app** no portal ou escolha uma chamada no aplicativo. A troca de sala é manual.
- Para compartilhar tela ou janelas, permita captura de tela nas configurações do sistema. Atualizações de teste no Mac podem exigir renovar essa permissão.

Os pacotes são de teste: Windows sem assinatura de editor; Mac com assinatura ad-hoc, sem notarização. Se o sistema bloquear, mantenha as proteções e utilize o navegador. Ainda falta validar câmera, áudio e transmissão em uma chamada real no Windows.

A barra de ferramentas pode aparecer na transmissão no Mac. A proteção contra captura está configurada para Windows compatível; as anotações permanecem visíveis.

Cada instalador tem um arquivo `.sha256` para conferir a integridade. Este repositório contém somente instruções e instaladores; o código do produto permanece privado.
